# 💼 FreelanceHub - Freelancer Platform

A modern, responsive freelancer marketplace built with pure HTML, CSS, and JavaScript (no frameworks).

## 🚀 Features

### Core Features
- **Browse Jobs**: Search and filter through available freelance opportunities
- **Post Jobs**: Clients can post new job listings
- **Apply for Jobs**: Freelancers can submit applications with cover letters
- **User Profile**: Manage your profile and view activity
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Local Storage**: All data persists in browser localStorage

### ✨ New in v2.0
- **🌙 Dark Mode**: Beautiful dark theme with smooth transitions
- **📄 Job Details Page**: Click any job to see complete information
- **❤️ Save/Bookmark Jobs**: Save favorite jobs for later
- **🔄 Advanced Sorting**: Sort by date or budget
- **🎨 Enhanced Animations**: Smooth fade-ins and toast notifications
- **⚡ Better UX**: Improved interactions and visual feedback

## ⚙️ How to Use

1. **Open the website**: Simply open `index.html` in your browser
2. **Browse Jobs**: Click "Browse Jobs" to see all available opportunities
3. **Filter Jobs**: Use search bar and filters (category, budget, experience)
4. **Apply**: Click "Apply" on any job card to submit an application
5. **Post a Job**: Navigate to "Post Job" to create a new listing
6. **Profile**: View and edit your profile information
