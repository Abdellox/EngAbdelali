# 🎓 MathMaster - Free Interactive Math Learning Platform

**Learn Math from Zero to Hero - A Free Open Source Educational Tool**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

MathMaster is a comprehensive, interactive web application designed to help anyone learn mathematics from absolute beginner to advanced levels. Built with pure HTML, CSS, and JavaScript - no frameworks required!

## 🌟 Features

### 📚 6 Progressive Learning Levels
- **Level 0**: Basic Counting (1-20, sequences, comparisons, even/odd)
- **Level 1**: Addition & Subtraction (single/double digit, word problems)
- **Level 2**: Multiplication & Division (times tables, squares, word problems)
- **Level 3**: Fractions & Decimals (operations, percentages, simplification)
- **Level 4**: Algebra & Equations (linear, quadratic, inequalities, systems)
- **Level 5**: Advanced Math (exponents, logarithms, derivatives, sequences, factorials)

### ✨ Enhanced Learning Features
- **🎲 Unlimited Questions** - Auto-generated with 30+ question types
- **💡 Smart Hints** - Get help when you're stuck
- **⏭️ Skip Option** - Move forward if needed
- **📊 Progress Tracking** - Accuracy, streaks, and total questions
- **💾 Auto-Save** - Your progress is saved automatically
- **🏆 Achievements** - Unlock rewards as you learn
- **🔥 Streak System** - Build momentum with correct answers
- **📝 Detailed Explanations** - Learn from every question

### 🎯 Question Variety

Each level includes multiple question types:

**Level 0**: Count forward/backward, compare numbers, sequences, missing numbers, even/odd
**Level 1**: Simple addition, double-digit addition, subtraction, word problems, missing addends
**Level 2**: Multiplication, division, word problems (both), squares
**Level 3**: Fraction addition/multiplication, decimal operations, percentages, simplification
**Level 4**: Linear equations, quadratics, two-step problems, word problems, inequalities, systems
**Level 5**: Exponents, logarithms, derivatives, sequences, factorials, combinations

## 🎮 How to Use

### Getting Started
1. **Download** or clone this repository
2. **Open** `index.html` in any modern web browser
3. **Choose** your level based on your current skills
4. **Start Learning** - Answer questions and improve!

### Tips for Success
- **Use Hints Wisely** - They're there to help you learn
- **Read Explanations** - Understanding is more important than speed
- **Build Streaks** - Try to get multiple correct answers in a row
- **Practice Daily** - Consistency is key to mastery
- **Challenge Yourself** - Move to the next level when ready

## 💻 Installation

### Option 1: Direct Use
```bash
# Clone the repository
git clone https://github.com/yourusername/mathmaster.git

# Navigate to directory
cd mathmaster

# Open in browser
# Double-click index.html
```

### Option 2: Local Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve

# Then open http://localhost:8000
```
