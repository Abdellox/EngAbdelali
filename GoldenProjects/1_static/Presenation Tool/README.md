# SlideFlow ✨

A modern, powerful, web-based presentation tool inspired by the best open-source presentation platforms. Create stunning presentations with zero setup!

## 🚀 Quick Start

1. **Open** `index.html` in your browser
2. **Create** slides using the visual editor or Markdown
3. **Customize** with themes, transitions, and layouts
4. **Present** with keyboard shortcuts and speaker notes
5. **Export** as standalone HTML or save as JSON

That's it! No installation, no build process, no server required.

## ✨ Key Features

### 🎨 **Dual Editing Modes**
- **Visual Editor**: Direct WYSIWYG editing - click and type
- **Markdown Mode**: Write in Markdown with live preview

### 🎯 **Rich Content**
- Text, headings, lists, tables
- Images (drag & drop or URL)
- Code blocks with syntax highlighting
- YouTube videos and video files
- Custom shapes with gradients

### 🎬 **Beautiful Transitions**
- 6 transition effects: Fade, Slide, Zoom, Flip, Cube, Rotate
- Smooth animations
- Progress bar and slide counter

### 📝 **Professional Features**
- **Speaker Notes**: Add notes visible only to you
- **Slide Overview**: Press 'O' to see all slides at once
- **Fullscreen Mode**: Distraction-free presenting
- **Slide Templates**: Title, Content, Two-Column, Quote
- **Drag to Reorder**: Rearrange slides easily

### 💾 **Smart Save System**
- Auto-save every 30 seconds
- Export as standalone HTML (works offline!)
- Save/Load as JSON
- Auto-restore on browser refresh

### ⚡ **Power User Features**
- Undo/Redo (Ctrl+Z/Y)
- Duplicate slides
- 4 beautiful themes
- Keyboard shortcuts
- Drag & drop images
- Gradient backgrounds

## ⌨️ Keyboard Shortcuts

**Presentation Mode:**
- `→` or `Space` - Next slide
- `←` - Previous slide
- `O` - Slide overview
- `N` - Toggle speaker notes
- `F` - Fullscreen
- `ESC` - Exit

**Editor Mode:**
- `Ctrl+Z` - Undo
- `Ctrl+Y` - Redo
- `Ctrl+S` - Save

## 🤝 Tips & Tricks

1. **Gradients**: In background gradient field, enter two colors separated by comma: `#667eea, #764ba2`
2. **Reorder Slides**: Drag slide thumbnails to rearrange
3. **Quick Templates**: Use template buttons for instant layouts
4. **Image Upload**: Drag images directly onto slides
5. **YouTube Videos**: Paste any YouTube URL, we'll extract the ID
6. **Auto-Restore**: Close browser accidentally? Your work is saved!
