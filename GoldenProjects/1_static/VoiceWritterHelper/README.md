# 🎤 Voice to Text - Free Writing Tool

A free, open-source speech-to-text web application designed to help writers, authors, and anyone who loves to write. Convert your voice into text effortlessly!

## ✨ Features

- **Real-time Speech Recognition** - Speak naturally and see your words appear instantly
- **Multi-language Support** - Supports 12+ languages including English, Spanish, French, German, Arabic, Chinese, and more
- **Continuous Recording** - Keep recording without interruption
- **Edit & Copy** - Edit the transcribed text and copy it with one click
- **Download as Text File** - Save your transcriptions as .txt files
- **Clean Interface** - Distraction-free design perfect for writers
- **100% Free** - No ads, no subscriptions, no hidden costs
- **Privacy First** - Everything runs in your browser, no data sent to servers

## 🚀 How to Use

1. Open `index.html` in your web browser (Chrome, Edge, or Safari recommended)
2. Allow microphone access when prompted
3. Select your preferred language
4. Click "Start Recording" and begin speaking
5. Click "Stop Recording" when done
6. Edit, copy, or download your text

## 🌐 Browser Support

Works best in:
- Google Chrome
- Microsoft Edge
- Safari

Note: Firefox has limited support for the Web Speech API.

## 💻 Installation

No installation needed! Just:
1. Download all files (index.html, style.css, script.js)
2. Open index.html in your browser
3. Start using it immediately

Or host it on any web server for online access.
