# Wallpaper Gallery - Web App

A beautiful web application to browse, preview, and download free wallpapers for your desktop or any device.

## Features

- Browse beautiful high-quality wallpapers
- Search by keywords or browse by categories
- Preview wallpapers in full size
- Download wallpapers in high resolution
- Responsive design - works on desktop, tablet, and mobile
- Free images from Unsplash

## Quick Start

Simply open `index.html` in your web browser!

No installation or setup required - just double-click the HTML file.

## Usage

1. **Browse Categories**: Click on category buttons (Nature, Space, Abstract, etc.)
2. **Search**: Type keywords in the search bar and press Enter
3. **Preview**: Click any wallpaper to see it in full size
4. **Download**: Click "Download Wallpaper" to save it to your device
5. **Set Preview**: Click "Set as Preview" to see how it looks as a background

## Setting as Desktop Wallpaper

After downloading:

**Windows:**
1. Right-click the downloaded image
2. Select "Set as desktop background"

**Mac:**
1. Open System Preferences > Desktop & Screen Saver
2. Click the + button and select your downloaded image

**Linux:**
1. Right-click desktop > Change Background
2. Select your downloaded image

## Optional: Use Real Unsplash API

The app works with demo images by default. For unlimited access:

1. Get a free API key from [Unsplash Developers](https://unsplash.com/developers)
2. Open `script.js`
3. Replace `YOUR_UNSPLASH_ACCESS_KEY` with your actual key
4. Change `DEMO_MODE` to `false`
