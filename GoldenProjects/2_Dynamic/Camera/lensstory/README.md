# 📷 LensStory - The Complete Evolution of Cameras

A comprehensive, beautifully designed web application showcasing the entire history of cameras and imaging technology, from ancient Camera Obscura to modern AI-powered computational photography.

## 🎨 Features

- **Complete Timeline**: 2,500 years of optical innovation with interactive timeline
- **Camera Encyclopedia**: Comprehensive database of all camera types
- **Technology Secrets**: Deep technical explanations made simple
- **Compare Tool**: Side-by-side comparison of cameras from different eras
- **Hall of Fame**: Iconic cameras that shaped photography history
- **Responsive Design**: Beautiful on all devices
- **Dark Mode**: Cinematic museum-style interface

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 📚 Content

The site includes detailed information about:
- Camera Obscura and early optical concepts
- First photography era (Daguerreotype, wet plates)
- Film era (35mm, SLR, instant cameras)
- Digital revolution (DSLR, sensors)
- Smartphone era (computational photography)
- AI and future cameras (light field, neural rendering)

## 🎯 Educational Focus

LensStory is designed as a knowledge hub for:
- Photography enthusiasts
- Technology historians
- Engineering students
- Curious learners

Every entry includes technical explanations, fun facts, and the "secrets" behind innovations.
