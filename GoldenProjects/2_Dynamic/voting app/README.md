# SecureVote - Blockchain-Based Voting Application

A comprehensive, secure, and accessible voting platform designed to address major issues in traditional voting systems.

## Key Features

- **Security**: Blockchain-based vote recording, end-to-end encryption, multi-factor authentication
- **Transparency**: Real-time tallying, audit trails, vote verification
- **Accessibility**: Multi-platform support, multi-language, disability-friendly
- **Privacy**: Voter anonymity with vote integrity
- **Scalability**: Designed for large-scale elections

## Tech Stack

- **Frontend**: React (Web), React Native (Mobile)
- **Backend**: Node.js with Express
- **Blockchain**: Ethereum/Hyperledger for vote recording
- **Database**: PostgreSQL (user data), MongoDB (audit logs)
- **Authentication**: OAuth2, JWT, Biometric APIs
- **Encryption**: AES-256, RSA

## Project Structure
