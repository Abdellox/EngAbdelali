# Book Summarizer 📚

An open-source tool that generates comprehensive summaries of books from PDF files or book titles. Perfect for book lovers who want to get the essence of a book quickly.

## Features

- Upload PDF files or provide book titles
- AI-powered comprehensive summaries
- Structured output with key themes, characters, and takeaways
- Free and open source

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Set up your OpenAI API key:
```bash
cp .env.example .env
# Edit .env and add your OPENAI_API_KEY
```

3. Run the application:
```bash
npm run dev
```

4. Open http://localhost:3000 in your browser

## Tech Stack

- Node.js + Express
- OpenAI API for summarization
- PDF parsing with pdf-parse
- Simple HTML/CSS/JS frontend
