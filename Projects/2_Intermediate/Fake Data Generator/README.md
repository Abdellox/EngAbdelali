# Fake Data Generator

A modern, easy-to-use fake data generator for developers. Generate realistic test data instantly!

## Features

- **13 Data Types**: Person, Name, Email, Phone, Username/Password, Address, Company, Credit Card, Identity, Internet, Vehicle, Bank Account, Biometric
- **Beautiful Card Layout**: Easy-to-read format with label: value pairs
- **Multiple Formats**: View as JSON or Cards
- **Copy to Clipboard**: One-click copy functionality
- **No Dependencies**: Pure vanilla JavaScript
- **Works Offline**: All data embedded, no external API calls
- **Huge Dataset**: Hundreds of names, cities, companies, and more

## How to Use

1. Open `index.html` in your web browser
2. Select the data type you want to generate
3. Choose how many records (1-100)
4. Click "Generate Data"
5. Copy the data or switch between JSON/Table view

## Data Types Available

- **🧑 Full Person** - Complete profile with ALL information
- **👤 Name Only** - First name, last name, full name
- **📧 Email Only** - Email addresses
- **📱 Phone Only** - Phone numbers
- **🔐 Username & Password** - Login credentials
- **🏠 Address Only** - Street, city, state, zip
- **🏢 Company & Job** - Company name and job title
- **💳 Credit Card** - Card type, number, expiration, CVV
- **🆔 Identity** - SSN, birthdate, age
- **🌐 Internet** - IP address, MAC address, website URL
- **🚗 Vehicle** - Make, model, year, color, VIN, license plate
- **🏦 Bank Account** - Account number, routing number, IBAN, SWIFT
- **🧬 Biometric** - Blood type, height, weight, eye color, hair color

## No Server Required

Just double-click `index.html` and it works! All data is embedded in the JavaScript file.
