## 📊 Download Flow

```
User pastes URL
    ↓
Frontend validates URL
    ↓
Check backend connectivity
    ↓
Fetch video info (title, thumbnail, duration)
    ↓
Display info to user
    ↓
Start download on backend
    ↓
Backend uses yt-dlp to download
    ↓
File saved to downloads/ folder
    ↓
Backend returns download URL
    ↓
Frontend auto-triggers browser download
    ↓
✅ File saved to user's Downloads folder!
```
