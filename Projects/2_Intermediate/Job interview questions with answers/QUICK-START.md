# 🚀 Quick Start Guide

## Access the Website

**URL**: http://localhost:8000

## First Time Visit

1. **Language Selection** appears automatically
2. Choose your language (or click English to continue)
3. Start exploring!

## Finding Jobs

### Method 1: Browse Categories
- Scroll through the colorful category cards
- Click any category to see jobs
- Click a job to start

### Method 2: Search
- Type in the search box at the top
- Results appear instantly
- Click any matching job

## Using Practice Mode

1. Select a job
2. Click **"Start Practice"**
3. Read each question
4. Click **"Show Answer"** to see the answer
5. Navigate with Previous/Next buttons
6. Study at your own pace

## Using Exam Mode

1. Select a job
2. Click **"Start Exam"**
3. Answer multiple-choice questions
4. Watch the timer (top right)
5. Navigate between questions
6. Click **"Submit Exam"** when done
7. See your score and review answers
8. Click **"Retake Exam"** to try again

## Tips for Best Results

### Practice Mode
- ✅ Read questions carefully
- ✅ Try to answer before revealing
- ✅ Take notes on key points
- ✅ Review multiple times

### Exam Mode
- ✅ Read all options before selecting
- ✅ Don't rush - accuracy matters
- ✅ Review unanswered questions
- ✅ Learn from mistakes in review
- ✅ Retake to improve score

## Scoring Guide

- **90-100%**: 🎉 Excellent! Interview ready!
- **70-89%**: 👍 Good! Minor review needed
- **50-69%**: 📚 Keep practicing
- **Below 50%**: 💪 Study more and retake

## Keyboard Shortcuts

- **Search**: Just start typing
- **Navigate**: Use arrow keys in practice mode
- **F12**: Open browser console for debugging

## Troubleshooting

### Page not loading?
- Check server is running
- Refresh page (Ctrl+F5)
- Clear browser cache

### Translation not working?
- Ensure internet connection
- Click 🔄 button to reset
- Refresh page

### Questions not showing?
- Open browser console (F12)
- Look for error messages
- Refresh page

## Reset Everything

Click the **🔄 button** (bottom-left) to:
- Reset language selection
- Clear all preferences
- Start fresh
