# 🎯 Round Table - Problem Solver

A community-driven platform where users gather wisdom and vote for the best solutions to real-world problems.

## ✨ Features
- ✅ 8 diverse categories with rich content
- ✅ 80+ pre-loaded problems with solutions
- ✅ Visitor mode with hot topics showcase
- ✅ User registration and voting system
- ✅ Beautiful split-screen layout
- ✅ Fully responsive mobile-first design
- ✅ Real-time vote tracking
- ✅ Add your own problems and solutions

## 🚀 How to Use
1. Open `index.html` in your browser
2. **Browse as visitor** - View all discussions and solutions
3. **Join Round Table** - Register with email to participate
4. **Vote** - Upvote the best solutions
5. **Contribute** - Add your own problems and solutions
6. **Filter** - Browse by category or view all

## 📂 Categories
1. 💻 **Technology** - Coding, hardware, software tips
2. 💪 **Health & Fitness** - Workouts, nutrition, wellness
3. 💼 **Career** - Job advice, interviews, promotions
4. 💰 **Finance** - Investing, budgeting, saving money
5. 📚 **Education** - Learning resources, study tips
6. 🏠 **Lifestyle** - Productivity, habits, organization
7. ❤️ **Relationships** - Communication, boundaries, friendships
8. ✈️ **Travel** - Destinations, packing, budget travel

## 🔧 Technical Details
- Pure vanilla JavaScript (no frameworks)
- LocalStorage for data persistence
- Responsive CSS Grid and Flexbox
- Mobile-optimized touch interactions
- Smooth animations and transitions

## 🗑️ Clear Data
To reset and start fresh, open browser console (F12) and run:
```javascript
localStorage.clear();
location.reload();
```
