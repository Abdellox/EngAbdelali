Understanding the Fundamentals

What is Hardware?

Hardware refers to the physical components of a computer system that you can touch and see:

  • CPU (Processor): The brain of the computer
  • RAM (Memory): Temporary storage for running programs
  • Hard Drive/SSD: Permanent storage for files
  • Motherboard: Connects all components
  • Input/Output: Keyboard, mouse, monitor, etc.

What is Software?

Software is the set of instructions that tells hardware what to do:

  • Operating Systems: Windows, Linux, macOS
  • Applications: Programs you use daily
  • Programming Languages: Tools to create software
  • Code: Instructions written by programmers
  • Algorithms: Step-by-step problem solutions
