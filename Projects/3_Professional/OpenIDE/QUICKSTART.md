# 🚀 Quick Start Guide - CodeFlow IDE

Get started with CodeFlow IDE in 60 seconds!

## Step 1: Open the IDE
Simply open `index.html` in your browser. That's it!

## Step 3: Try These Features

### 🎯 Smart Autocomplete
1. Type `log` and press **Tab** → `console.log()`
2. Type `func` and press **Tab** → Full function template
3. Type `class` and press **Tab** → Class declaration

### ⌨️ Essential Shortcuts
- **Ctrl+P** - Command Palette (try it now!)
- **Ctrl+Enter** - Run your JavaScript code
- **Ctrl+S** - Download your file
- **Ctrl+Space** - Force autocomplete suggestions

### 🎨 Change Language
1. Click the language dropdown (top bar)
2. Select any language (Python, Java, HTML, etc.)
3. Start typing - snippets change automatically!

### 💡 Command Palette (Ctrl+P)
Press **Ctrl+P** and type:
- "Run" → Execute code
- "Format" → Format your code
- "Theme" → Change theme
- "New" → Create new file

## Step 4: Write Your First Code

### JavaScript Example:
```javascript
// Type 'func' and press Tab
function greet(name) {
    // Type 'log' and press Tab
    console.log(`Hello, ${name}!`);
}

greet("World");
```
Press **Ctrl+Enter** to run!

### Python Example:
Change language to Python, then:
```python
# Type 'def' and press Tab
def greet(name):
    # Type 'print' and press Tab
    print(f"Hello, {name}!")

greet("World")
```

### HTML Example:
Change language to HTML, then:
```html
<!-- Type 'html5' and press Tab -->
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My Page</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>
```

## Step 5: Pro Tips

### 🔥 Power User Moves
1. **Right-click** in editor → Context menu with quick actions
2. **Ctrl+B** → Toggle sidebar for more space
3. **Alt+Shift+F** → Auto-format messy code
4. **Ctrl+/** → Comment/uncomment lines
5. **Alt+Up/Down** → Move lines up or down

### 🎯 Snippet Cheat Sheet

**JavaScript:**
- `log` → console.log()
- `func` → function
- `arrow` → arrow function
- `class` → class
- `for` → for loop
- `if` → if statement
- `try` → try-catch

**Python:**
- `print` → print()
- `def` → function
- `class` → class
- `for` → for loop
- `if` → if statement
- `try` → try-except

**CSS:**
- `flex` → flexbox
- `grid` → grid layout
- `gradient` → linear gradient
- `shadow` → box shadow

### 🎨 Themes
Try different themes:
1. Click theme dropdown
2. Choose: Dark, Light, or High Contrast
3. Find your perfect coding environment!

## Step 6: Create Multiple Files

1. Click **+ New** button (or press Ctrl+N)
2. Enter filename: `script.js`, `style.css`, `index.html`
3. Switch between files using tabs or sidebar
4. Each file remembers its content!

## Step 7: Download Your Work

- **Ctrl+S** → Download current file
- File saves with correct extension
- Open in any text editor or IDE

## 🆘 Troubleshooting

**Autocomplete not working?**
- Press **Ctrl+Space** to trigger manually
- Make sure you selected the right language

**Code won't run?**
- Only JavaScript runs in browser
- Other languages need backend server
- Check browser console for errors

**Shortcuts not working?**
- Make sure you're focused on the editor
- Try clicking in the editor first
- Check if browser shortcuts conflict
