# CodeFlow IDE ⚡

A free, open-source, browser-based IDE with superpowers! Works on all modern browsers with zero installation. Perfect for beginners and powerful enough for professionals.

## ✨ Features

### 🚀 Core Features
- **15+ Language Support**: JavaScript, TypeScript, Python, Java, C++, C#, HTML, CSS, JSON, Markdown, SQL, PHP, Ruby, Go, Rust
- **Smart Autocomplete**: Language-specific snippets and intelligent suggestions powered by Monaco Editor
- **Live Code Execution**: Run JavaScript code instantly in the browser
- **Beautiful UI**: Modern interface with smooth animations and transitions
- **Multiple Themes**: Dark, Light, and High Contrast themes
- **File Management**: Create, edit, switch between, and download multiple files

### 💡 Advanced Features
- **Command Palette** (Ctrl+P): Quick access to all IDE commands
- **Context Menu**: Right-click for quick actions (Cut, Copy, Paste, Format, Run)
- **Toast Notifications**: Beautiful notifications for all actions
- **Smart Tooltips**: Hover over buttons to see keyboard shortcuts
- **Syntax Highlighting**: Beautiful, language-specific syntax coloring
- **Code Formatting**: Auto-format code with Alt+Shift+F
- **Minimap Navigation**: Quick code overview and navigation
- **Bracket Pair Colorization**: Easy to match brackets and parentheses
- **Smooth Scrolling**: Buttery smooth editor experience
- **Cursor Animations**: Smooth cursor movements and blinking

### 🎯 Language-Specific Snippets

Each language comes with pre-configured snippets:

**JavaScript/TypeScript:**
- `log` → console.log()
- `func` → function declaration
- `arrow` → arrow function
- `class` → class declaration
- `async` → async function
- `promise` → Promise
- `try` → try-catch block
- `for`, `foreach`, `map`, `filter`, `reduce`

**Python:**
- `print` → print statement
- `def` → function definition
- `class` → class definition
- `if`, `for`, `while` → control structures
- `try` → try-except block
- `with` → with statement
- `list`, `dict` → comprehensions

**HTML:**
- `html5` → HTML5 boilerplate
- `div`, `link`, `script`, `img`, `a`, `button`, `form`

**CSS:**
- `flex` → flexbox layout
- `grid` → grid layout
- `transition`, `animation`, `gradient`, `shadow`

**Java:**
- `main` → main method
- `class` → class declaration
- `sout` → System.out.println
- `for`, `if`, `try`

## 🎯 Getting Started

1. **Open the IDE**: Simply open `index.html` in any modern browser
2. **Welcome Screen**: Click "Start Coding" or wait for auto-start
3. **Select Language**: Choose from 15+ languages in the dropdown
4. **Start Typing**: Use autocomplete (Ctrl+Space) for suggestions
5. **Try Snippets**: Type snippet keywords (like `log`, `func`, `class`) and press Tab
6. **Run Code**: Click Run or press Ctrl+Enter (JavaScript only)
7. **Command Palette**: Press Ctrl+P for quick access to all features
8. **Download**: Save your work with Ctrl+S

- Other languages require backend server for execution
- No file system access (browser security)
- Files are stored in memory only
