# PDFTools - Professional PDF Editor & Tools

A complete PDF editing and manipulation suite that runs entirely in your browser. Edit PDFs like a pro with full text editing, image insertion, signatures, and more!

## 🌟 MAIN FEATURE: Full PDF Editor

The **Edit PDF** tool is the star of this application, offering comprehensive editing capabilities:

### ✏️ Text Editing
- Add text anywhere on the PDF
- Change font size (8-72px)
- Choose font family (Helvetica, Times, Courier)
- Change text color
- Move text elements by dragging
- Delete individual text elements

### 🖼️ Image Management
- Insert images anywhere on the PDF
- Resize images
- Move images by dragging
- Support for JPG and PNG

### ✍️ Signatures
- Add signature text with special styling
- Position signatures anywhere
- Italic and bold formatting

### 🔗 Links
- Add clickable links to PDFs
- Custom link text
- Blue underlined styling

### 🎨 Full Control
- Multi-page support with navigation
- Drag and drop elements
- Delete individual elements
- Clear all elements from a page
- Save edited PDF with all changes

## 📦 Additional Tools

### Merge PDF
Combine multiple PDF files into one document

### Split PDF
Extract specific page ranges from a PDF

### Compress PDF
Reduce PDF file size while maintaining quality

### PDF to JPG
Convert all PDF pages to high-quality JPG images (downloads as ZIP)

### JPG to PDF
Create a PDF from multiple images

### Rotate PDF
Rotate pages 90°, 180°, or 270°

### Add Watermark
Add custom text watermarks to all pages

### Delete Pages
Remove specific pages from a PDF

## 🔒 Privacy & Security

- **100% Client-Side Processing** - All files are processed locally in your browser
- **No Uploads** - Your files never leave your device
- **No Server** - Everything runs in JavaScript
- **Completely Private** - No data collection or tracking

## 🚀 Technologies

- **PDF.js** - For rendering and viewing PDFs
- **PDF-lib** - For PDF manipulation and editing
- **JSZip** - For creating ZIP archives
- **Pure JavaScript** - No frameworks, fast and lightweight

## 💻 Usage

1. Open `index.html` in any modern browser
2. Click on "Edit PDF" (the featured card) for full editing
3. Or choose any other tool for specific operations
4. Upload your PDF or images
5. Make your changes
6. Download the result
