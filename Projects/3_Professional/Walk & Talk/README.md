# 🚶 Walk & Talk - Walking Conversation Partner

A platform connecting people who want to walk together and have meaningful conversations. Perfect for reducing stress, staying active, and building human connections.

## Features

- **Find Walking Partners**: Browse professional life coaches, therapists, and friendly companions
- **Choose Routes**: Select from parks, gardens, and city centers with interactive maps
- **Conversation Styles**: Pick your vibe - calm, motivational, or deep chat
- **User Profiles**: Track your walking stats and preferences
- **Booking System**: Easy scheduling with your chosen walker

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React 18
- React Router for navigation
- Leaflet for interactive maps
- Vite for fast development
- Modern CSS with gradients and animations

## Why Walk & Talk?

People need someone to listen. Walking while talking reduces stress, improves mental health, and creates genuine human connections in a healthy, active way.
