# YouTube to Transcript

A modern, clean web application for generating YouTube video transcripts.

## Features

- 🎬 Extract transcripts from any YouTube video
- 🌍 Support for multiple languages
- 🔄 Translate transcripts to 125+ languages
- 📋 Easy copy and download functionality
- ⏱️ Toggle timestamps on/off
- ✏️ Editable transcript text
- 📱 Fully responsive design
- 🎨 Modern dark theme interface

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the server:
```bash
npm start
```

3. Open your browser and go to:
```
http://localhost:3000
```

## How It Works

The application uses a Node.js backend to fetch YouTube transcripts:
- **Backend**: Express server with `youtube-transcript` package
- **Frontend**: Clean, modern interface with dark/light mode
- **No API Keys Required**: Works directly with YouTube's public caption data

## Technologies

- Pure HTML, CSS, and JavaScript
- No frameworks required
- Modern CSS Grid and Flexbox
- Responsive design
- Dark theme optimized
