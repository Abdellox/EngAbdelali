# Quick Start Guide

## Installation & Running

1. **Install Node.js** (if not already installed)
   - Download from: https://nodejs.org/

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the server**
   ```bash
   npm start
   ```

4. **Open in browser**
   - Go to: http://localhost:3000
   - Paste any YouTube video URL
   - Click "Generate Transcript"

## Features

✅ **Real YouTube Transcripts** - Fetches actual captions from any YouTube video
✅ **Multiple Languages** - Supports all available caption languages
✅ **Light/Dark Mode** - Toggle with the moon/sun icon
✅ **Copy & Download** - Easy export options
✅ **Timestamps** - Toggle on/off as needed
✅ **Editable** - Click transcript to edit before copying

## Troubleshooting

**Error: "Could not fetch transcripts"**
- The video may not have captions/subtitles enabled
- Try a different video with captions

**Server won't start**
- Make sure port 3000 is not in use
- Run `npm install` first

**Module not found errors**
- Delete `node_modules` folder
- Run `npm install` again
