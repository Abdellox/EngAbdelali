# Start with Python Backend

## Installation

1. **Install Python** (if not installed)
   - Download from: https://www.python.org/downloads/

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the server**
   ```bash
   python transcript_server.py
   ```

4. **Open in browser**
   - Go to: http://localhost:3000
   - Paste any YouTube video URL
   - Click "Generate Transcript"

## Why Python?

Python's `youtube-transcript-api` is the most reliable library for fetching YouTube transcripts. It's actively maintained and works consistently.
