## Maintenance

### Update Projects
To refresh project data:
1. Edit `backend/seedProjects.js`
2. Delete `backend/codeshare.db`
3. Restart backend server
4. Run seed script

### Add New Categories
1. Edit `backend/database.js`
2. Add category in `seedData()` function
3. Restart server
