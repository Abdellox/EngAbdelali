## 🔧 Useful Commands

### Check Project Count
```bash
cd backend
node checkProjects.js
```

### Test API
```bash
cd backend
node testAPI.js
```

### Add More Projects
```bash
cd backend
# Edit addMoreProjects.js
node addMoreProjects.js
```

### Restart Servers
If servers stop, restart them:
```bash
# Backend
cd backend
npm start

# Frontend (in new terminal)
cd frontend
npm start
```
